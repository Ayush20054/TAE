# Library Registration Form

## Overview

This project is a simple, responsive web-based Library Registration Form built using HTML, CSS, and JavaScript. It allows users to fill out a registration form, review their information, and submit it. The form includes fields for personal details such as name, username, email, password, phone number, address, date of birth, student type, and gender.

## Features

- **User-Friendly Form**: Collects essential user information with validation for required fields.
- **Review Section**: Users can review their entered information before final submission.
- **Responsive Design**: The form is styled to be mobile-friendly and visually appealing, with a background image.
- **Submission Confirmation**: Displays a thank-you message upon successful submission.
- **No Backend**: This is a frontend-only application; data is not stored or processed server-side.

## Technologies Used

- **HTML5**: Structure of the web page and form elements.
- **CSS3**: Styling for layout, colors, and responsiveness.
- **JavaScript (ES6)**: Handles form interactions, review display, and submission logic.

## File Structure

- `index.html`: Main HTML file containing the form structure.
- `styles.css`: CSS file for styling the form and page layout.
- `scripts.js`: JavaScript file for form functionality.
- `D.jfif`: Background image used in the CSS.
- `README.md`: This file, providing project documentation.

## How to Run

1. **Clone or Download**: Ensure all files are in the same directory.
2. **Open in Browser**: Double-click `index.html` or open it in any modern web browser (e.g., Chrome, Firefox).
3. **Interact**: Fill out the form, click "Review Information" to preview, and then "Submit" to complete.

No server or additional setup is required, as this is a static website.

## Usage

1. Open `index.html` in a web browser.
2. Fill in all required fields in the registration form.
3. Click the "Review Information" button to view a summary of your inputs.
4. If satisfied, click "Submit" to finalize the registration.
5. A confirmation message will appear.

## Browser Compatibility

- Tested on modern browsers: Chrome, Firefox, Safari, Edge.
- Requires JavaScript enabled for full functionality.
